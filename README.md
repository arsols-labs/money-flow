# Money Flow

Structured tool for AI and human: AI agents/bots operate it through an MCP bridge; Humans use the built-in frontend. Privacy-first money-flow data on Cloudflare Workers, D1, KV, and Passkeys. The public repository is live; the full application source is still rolling out with the first public release.
